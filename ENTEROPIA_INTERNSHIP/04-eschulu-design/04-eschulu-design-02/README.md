# EduFlow — Education Management Platform

## Project Overview
EduFlow is a fictional education management SaaS platform created for the Enteropia LLP Frontend Development Internship Challenge.

It provides a friendly public marketing website and an interactive campus management dashboard.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Public Website Features
1. Responsive navigation
2. Animated hero section
3. Interactive dashboard preview
4. Feature cards
5. Eight education management modules
6. Pricing plans
7. Contact section
8. Responsive layouts

## Dashboard Features
1. Admin dashboard
2. Teacher demo view
3. Student demo view
4. Student management
5. Faculty management
6. Attendance management
7. Timetable
8. Fees and finance
9. Admissions
10. Learning management system
11. Examinations
12. Settings
13. Dashboard charts and statistics
14. Search and status filters
15. Add-record forms
16. Notifications
17. Responsive sidebar

## How to Run
1. Open the folder in Visual Studio Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. Click Try the demo.
5. Explore the dashboard and switch between the demo roles.

## Limitations
- Frontend demonstration only.
- Login is simulated.
- No backend or database is connected.
- Dashboard records are sample JavaScript data.
- Role selection is not secure authentication.
- Financial information is illustrative.
- No real payments are processed.

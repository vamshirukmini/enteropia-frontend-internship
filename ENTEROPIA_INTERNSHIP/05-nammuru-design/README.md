# NAMMURU — Local Discovery & Tourism

## Project Overview
NAMMURU is a fictional local discovery and tourism platform created for the Enteropia LLP Frontend Development Internship Challenge.

It helps visitors discover destinations, local businesses, cultural experiences and events.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash photography

## Website Features
1. Full-screen travel hero section
2. Destination search
3. Category filters
4. Destination cards
5. Travel editorial feature section
6. Local business listings
7. Events and festivals section
8. Newsletter signup interaction
9. Community listing submission form
10. Responsive navigation
11. Image hover animations
12. Responsive layouts

## How to Run
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. Explore destinations, businesses and events.
5. Try searching and filtering destinations.
6. Use Add a listing to submit a sample listing.

## Limitations
- This is a frontend demonstration.
- No backend or database is connected.
- Destination and business information is sample content.
- Listing submissions are stored only in the current page session.
- Newsletter signup is simulated.
- No real booking or payment system is connected.
- Images are loaded from Unsplash and require an internet connection.

# OORU – Local Discovery & Tourism Platform

## Project Overview
OORU is a responsive local discovery website concept designed to help users explore destinations, local businesses and community events across Karnataka.

## Design Direction
Modern, colorful and interactive discovery platform.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## Features
- Responsive navigation
- Destination search
- Category-based filtering
- Destination cards
- Interactive map-style preview
- Local business showcase
- Community events section
- Add listing modal
- Form validation
- Toast notifications
- Mobile responsive layout
- Reduced-motion accessibility support

## How to Run
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open index.html.
4. Right-click and select Open with Live Server.

## Important Notes
- This is a frontend demonstration project.
- Destination and business content is sample content.
- The map is a visual demonstration, not a live map integration.
- Listing submissions are not stored in a database or sent to a server.
- Event dates are sample content and are not verified schedules.
- External images and Google Fonts require an internet connection.

## Responsive Testing
